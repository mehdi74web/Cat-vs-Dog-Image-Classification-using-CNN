# Cat-vs-Dog-Image-Classification-using-CNN
This project is a Deep Learning-based image classification model that distinguishes between cats and dogs using a Convolutional Neural Network (CNN).
📌 Features
Binary image classification (Cat 🐱 vs Dog 🐶)
Data preprocessing and normalization
Data augmentation for better generalization
CNN model with convolution, pooling, and dense layers
Model evaluation on test dataset
🛠️ Technologies Used
Python
TensorFlow / Keras
NumPy
Matplotlib
📂 Dataset

The dataset contains images of cats and dogs organized into training and testing sets.

⚙️ Model Architecture
Convolution Layer + ReLU
MaxPooling Layer
Multiple Conv + Pool layers
Flatten Layer
Fully Connected Dense Layers
Output Layer (Sigmoid)
📊 Results
Achieved good accuracy on validation data
Model successfully classifies unseen images
